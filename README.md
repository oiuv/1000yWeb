# 云端千年 · 炎黄新章游戏官网

基于 Node.js / Express 的游戏网站，提供客户端下载、账号管理、每日榜单和充值登记。前端使用原生 HTML、CSS 和 JavaScript，无需单独构建。

## 功能

- 客户端下载、安装指引与使用说明
- 游戏参考资料、分类浏览与全文搜索
- 账号注册、登录及个人资料管理
- 每日英雄榜与历史榜单查询
- 充值登记、进度查询及后台管理
- 管理员分页查询注册账号、角色、注册时间、最后游戏时间与付费状态
- 适配桌面和手机的页面布局

## 环境要求

- Node.js 22.x 或 24.x
- npm
- 正式运行所需的数据源与配置；本地预览不需要

SQLite 依赖包含原生扩展。更换 Node.js 主版本后，请重新执行 `npm ci`，或使用 `npm rebuild better-sqlite3` 重建。

```sh
npm ci

```

打开 <http://127.0.0.1:4318>。预览使用内存演示数据，不读取正式配置或连接游戏数据库；演示账号见启动输出，退出后数据不保留。预览服务不能用于正式部署。

## 配置与运行

将 [.env.example](.env.example) 复制为 `.env`，按实际环境配置数据库连接、管理员和所需的可选功能，然后启动：

```sh
npm start
```

默认地址为 `http://127.0.0.1:3000`；开发时可用 `npm run dev` 自动重载。

生产环境设置 `NODE_ENV=production`，配置 `APP_ORIGIN`，通过 HTTPS 反向代理访问。`TRUST_PROXY` 只信任实际代理，数据库使用最小权限账号。不要提交 `.env`、凭据、运行数据库、备份或玩家数据，也不要将这些文件放入 `public/`。

网站会话绑定登录时的账号身份和密码；游戏端或其他入口改密后，旧网站会话在下一次请求时失效。
更新到此会话格式时，已有网站登录需要重新登录一次，充值记录不受影响。游戏账号的密码存储格式保持兼容。
请求接口只接受未压缩的 JSON，网站表单无需调整。充值数据库路径会检查实际目录及目录链接，禁止放入公开目录；静态服务也拒绝数据库、日志及备份文件。

## 管理中心

管理中心提供用户管理、付费状态和充值管理三个入口，仅管理员可访问对应接口。
用户列表支持按账号或角色名搜索，每页可显示 20、50 或 100 条。角色来自账号的已创建角色槽位，
不表示角色当前在线；最后游戏时间沿用游戏账号记录，原记录只有日期时不补造时分秒。

付费状态读取同机 Paid 的 `user_paid` 表，按账号精确匹配大小写，显示付费模式、有效期、
建立及更新时间。禁用优先于到期判断，其余状态按本机时间与到期时间比较，与 Paid 的管理口径一致。
查询成功但没有付费记录的账号，在用户列表中显示“不限时试用／无固定到期日”：Paid 每次查询按模式 `001`
重新计算当次试用时长，不为这类账号建立固定的账号到期日。这里不把当次试用截止时间显示为账号有效期，
也不表示单次在线时长无限制。模式 `100` 显示为包时，模式 `000` 显示为禁用。
已录入数据库的 `001` 记录仍按其保存的到期时间显示；`200`、`400` 保留对应模式，避免误判。
未配置数据来源、读取失败和异常记录分别显示，不能当作默认试用。
该页面只读查询，不修改付费期限或充值登记；充值登记的审核与交付流程保持独立。

查询付费状态与禁用账号使用 `PAID_DB_PATH`；自动充值还需同时配置 `PAID_PYTHON` 与
`PAID_RECHARGE_SCRIPT`。数据库必须已存在且位于公开目录之外，查询需要读取权限，禁用需要写入权限。
账号列表使用现有 SQL Server 账号库的 `account1000y` 表，需要读取账号、角色槽位、注册及最后游戏日期字段。
列表接口不返回密码、密保、电话或邮箱；付费数据不可读时仍可查看账号列表。

用户管理仅提供“禁用账号”，确认后写入模式 `000`。无付费记录的试用账号也可禁用：
新建禁用记录，按禁用时刻填写 Paid 协议所需的非空日期，不授予付费时长；已有记录保留原有效期。
操作人、原因及原模式、原到期时间写入 Paid 库的 `web_account_disables`，与禁用写入在同一事务完成。
重复禁用不会重复记账；账号大小写冲突须先经 Paid 管理核对。禁用在游戏下次付费校验时生效，不强制踢出在线角色。

网站不提供启用、删除付费记录、任意修改付费模式或手动设置有效期的接口。有效期仅由充值管理中的已核准订单充值。
模式 `000` 禁止充值；网站在核款、重试前检查，Paid 充值事务再次检查模式，并与禁用操作串行获取 SQLite 写锁。
禁用后重放旧订单收据也不会修改账号模式或有效期。特殊解禁只通过 Paid 服务管理删除禁用记录，恢复默认试用。

## 开发说明

游戏资料为随代码发布的静态页面，部署无需重新生成。更新方式见[资料维护说明](scripts/GUIDES.md)。

- 页面与静态资源位于 `public/`，客户端下载入口为 `public/download.html`。
- `server.js` 为运行入口，`app.js` 负责应用组装；接口和数据访问位于 `routes/`、`models/`。
- `tests/` 存放测试，`scripts/preview.js` 提供隔离预览。
- 公开文档只保留项目简介、通用用法及必要维护说明，不收录内部运营流程、私有部署资料或真实业务数据。
